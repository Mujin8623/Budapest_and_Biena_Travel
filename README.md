# 비엔나 · 부다페스트

2026년 11월 27일–12월 6일 여행 일정. GitHub Pages는 `main`의 루트에서 배포합니다.

## 일정표

하단 **일정표**에서 하루 시간표를 보고, 일정을 끌어 시각을 바꿀 수 있습니다. 키보드와 좁은 화면에서는 블록의 **시간 수정**으로 날짜와 시각을 바꿉니다.

바꾼 시각은 그 브라우저의 `localStorage`(`trip-schedule-v1`)에만 저장됩니다. 다른 기기나 다른 사람과 자동으로 동기화되지 않고, 저장소의 기본 일정·비용은 바뀌지 않습니다. 실행 취소와 기본 일정으로 되돌리기가 있습니다. 예약된 항공·기차·입장 시각은 확인 없이 움직이지 않으며, 화면에서 옮겨도 실제 예약은 바뀌지 않습니다. 일정표는 이동 시간을 다시 계산하지 않습니다.

## 문서함

숙소 바우처와 기차표는 `data/vault.js`에 AES-GCM 암호문으로만 있습니다. 앱의 문서함 탭에서 비밀번호로 엽니다. 비밀번호와 원본 PDF는 저장소에 넣지 않습니다.

형식, salt를 유지한 채 문서를 추가하는 방법, `TRAVEL_DOCS_PASSWORD`로 실행하는 `tools/encrypt_vault.py` 사용법은 [docs/VAULT.md](docs/VAULT.md)에 있습니다.
