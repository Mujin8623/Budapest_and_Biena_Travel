## 문서함

숙소 바우처와 기차표는 `data/vault.js`에 AES-GCM 암호문으로만 있습니다. 앱의 문서함 탭에서 비밀번호로 엽니다. 비밀번호와 원본 PDF는 저장소에 넣지 않습니다.

형식, salt를 유지한 채 문서를 추가하는 방법, `TRAVEL_DOCS_PASSWORD`로 실행하는 `tools/encrypt_vault.py` 사용법은 [docs/VAULT.md](docs/VAULT.md)에 있습니다.
